# php-web-fundamentos

Repositório de estudos sobre desenvolvimento web com **PHP puro**, focado em entender como a web funciona por baixo dos panos: protocolo HTTP, requisições, formulários, sessões e renderização de páginas no servidor.

Este projeto é **exclusivamente sobre o aprendizado de web em PHP** — não utiliza banco de dados nesta fase. O foco está em consolidar os fundamentos da linguagem no contexto web antes de avançar para persistência de dados.

## Sobre o repositório

Aqui você vai encontrar duas coisas:

1. **Anotações e exemplos de estudo** — códigos pequenos, testes e resumos do que estou aprendendo sobre PHP no contexto web.
2. **Projeto blog** — um blog desenvolvido em aula acompanhando as orientações do professor, aplicando os conceitos estudados.

## Tecnologias

- **PHP** (sem framework, sem banco de dados)
- **HTML5**
- **CSS3**

## Tópicos estudados
- Funcionamento do protocolo HTTP (métodos GET, POST, status codes)
- Ciclo requisição/resposta entre cliente e servidor
- Estrutura de um servidor web e como o PHP é processado
- Formulários e envio de dados
- Variáveis superglobais (`$_GET`, `$_POST`, `$_SERVER`, `$_SESSION`)
- Inclusão de arquivos (`include`, `require`)
- Estruturação de páginas com PHP + HTML
